# Projeto CBF — Teste exploratório

**Status: preparação da sessão de testes.**

Este repositório registra o trabalho de QA de Andeil Abreu na plataforma de
observação de jogadores usada pelos observadores técnicos das seleções
brasileiras de base.

O objetivo desta etapa é fazer um **teste exploratório**: usar a plataforma
como um usuário real, observar o comportamento e registrar o que funciona, o
que falha e o que está indefinido.

## Avisos importantes

- Este repositório é público.
- Credenciais de acesso **não** devem ser gravadas aqui.
- A plataforma está em produção. Os testes devem respeitar os critérios de
  aceite do ticket.
- Dados criados nos testes devem usar o prefixo `[TESTE]`.
- Este trabalho não deve ser apresentado como experiência profissional antiga.
  É uma atividade atual de QA.

## Ambiente
