# Dados de teste

## Convenção

Todo clube, atleta ou avaliação criado neste projeto deve começar com
`[TESTE]`.

## Exemplos de nomes

Os valores abaixo são fictícios e poderão ser usados na sessão:

- Clube: `[TESTE] Clube Base 01`
- Atleta: `[TESTE] Atleta Base 01`
- Avaliação: `[TESTE] Avaliação observador 01`

## O que não deve ser criado neste arquivo

- senhas;
- tokens;
- dados pessoais reais;
- nomes de clubes ou jogadores já existentes na plataforma.
